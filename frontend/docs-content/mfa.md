# Multi-Factor Authentication (MFA)

In an era of relentless phishing campaigns and credential stuffing attacks, a password alone is no longer sufficient to protect sensitive enterprise infrastructure. API Guardian strongly emphasizes the use of Multi-Factor Authentication (MFA) to safeguard your account and, by extension, your organization's source code and deployment pipelines.

## How MFA Works in API Guardian
API Guardian supports Time-based One-Time Passwords (TOTP). This is an industry-standard algorithm (RFC 6238) supported by all major authenticator applications, including Google Authenticator, Microsoft Authenticator, Authy, and hardware tokens like YubiKey (via Yubico Authenticator).

When you log in with your email and password, the system verifies your credentials. If MFA is enabled, the backend does *not* issue a final JWT access token. Instead, it issues a temporary `mfa_token`. You must then provide the 6-digit code currently displayed on your authenticator app. Only upon successful validation of this code will the final, fully-privileged access token be issued.

## Enabling MFA
To enable MFA, navigate to the **Security** tab in your personal User Settings. 
1. Click "Enable Two-Factor Authentication".
2. The platform will generate a secure TOTP secret and display it as a QR code.
3. Scan the QR code with your preferred authenticator app.
4. Enter the 6-digit code generated by the app to verify the setup.

Upon successful verification, MFA is permanently enabled for your account. You will also be provided with a set of one-time recovery codes. **Store these securely in a password manager.** If you lose access to your authenticator device, these codes are the only way to regain access to your account.

## Enterprise Enforcement
For organizations on the Enterprise tier, Organization Owners can mandate MFA compliance. By toggling "Enforce MFA" in the Organization Security settings, any member who does not have MFA enabled will be immediately logged out and forced to configure it upon their next login attempt. This guarantees a uniform, high-security baseline across your entire engineering team.
